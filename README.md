## 1. Opis otvorenog skupa podataka
Skup podataka sadrži popis modela koji su bili/jesu Victoria's Secret Angels, zajedno s popisom modnih revija na kojima su sudjelovali. Svaka modna revija sadrži, između ostalog, i popis izvođača koji su na njoj nastupali. Podaci su preuzeti s Wikipedije ili prikupljeni vlastitim promatranjem i pregledom snimki modnih revija.

## 6. Opis atributa

| Atribut | Tip podatka | Opis |
|---|---|---|
| `angel_id` | Broj | Jedinstveni identifikator modela. |
| `name` | Tekst | Ime modela. |
| `surname` | Tekst | Prezime modela. |
| `date_of_birth` | Datum | Datum rođenja u formatu `YYYY-MM-DD`. |
| `nationality` | Tekst | Nacionalnost modela. |
| `height_cm` | Broj | Visina modela u centimetrima. |
| `active_from_year` | Broj | Godina prve revije modela. |
| `active_to_year` | Broj | Godina završetka aktivnog rada. |
| `status` | Tekst | Status suradnje, primjerice `active` ili `inactive`. |
| `hair_color` | Tekst | Boja kose modela. |
| `eye_color` | Tekst | Boja očiju modela. |
| `agency` | Tekst | Modna agencija koja zastupa model. |
| `shows` | Lista objekata | Popis modnih revija na kojima je model sudjelovao. |
| `show_year` | Broj | Godina održavanja revije. |
| `show_city` | Tekst | Grad održavanja revije. |
| `venue` | Tekst | Lokacija održavanja revije. |
| `performers` | Lista objekata | Popis izvođača na reviji. |
| `performer_name` | Tekst | Umjetničko ili skraćeno ime izvođača. |
| `performer_fullname` | Tekst | Puno ime i prezime izvođača. |
